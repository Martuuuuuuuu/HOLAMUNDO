# Hola Mundo - C++

## Descripción

Este proyecto tiene como objetivo comprobar el correcto funcionamiento del compilador **g++ (GCC)** en **Visual Studio Code**.

Se desarrolló un programa básico en C++ que muestra un mensaje de "Hola Mundo" en la consola. La actividad permite verificar la configuración del entorno, la compilación y la ejecución de un programa desde Visual Studio Code.

## Entorno

- Sistema operativo: Windows
- Editor: Visual Studio Code
- Lenguaje: C++
- Compilador: g++ (GCC)
- Extensión: C/C++ de Microsoft

## Estructura

- `src/`: código fuente.
- `Docs/`: documentación.
- `Capturas/`: evidencias de la actividad.
